Ward Seva — An App for Nagar Sevak

A mobile app that gives citizens a direct, trackable way to report local civic issues to their Nagar Sevak's (local representative's) team.

Solo project GitHub repository coming soon
🚧 In development — not yet published to GitHub

The problem

Residents regularly deal with civic issues — potholes, overflowing garbage, water-supply problems, broken streetlights, blocked drainage, damaged roads, street-animal welfare concerns, and noise pollution — but there's usually no direct, trackable channel between a citizen and the local representative's (Nagar Sevak's) team to actually get them fixed.

The solution

Ward Seva lets a citizen report any of these issues in a few taps. The app captures a photo of the affected area directly through the in-app camera (so the evidence is current and genuine, not an old photo), and attaches the location — either typed manually or auto-detected — before sending the report straight to an admin panel. From there, the Nagar Sevak's team can see exactly what the problem is, where it is, and dispatch the right people to fix it.

Tech stack

Flutter Dart Device Camera Integration Geolocation

Key features & challenges

  • Getting accurate auto-detected location without forcing the user through a clunky manual process when GPS is unreliable (e.g. indoors or in dense areas).
  • Structuring complaint categories (potholes, garbage, water supply, streetlights, drainage, road damage, street animals, noise pollution) so reports are easy to triage on the admin side.
  • Designing an admin panel that non-technical civic staff can actually use to action reports quickly.
