Twitter Sentiment Analyzer

An NLP pipeline that classifies tweets as positive, negative, or neutral, built during my Persevex AI internship and deployed as a live REST API.

GitHub ↗ Solo project Persevex Internship

The problem

Reading through thousands of tweets by hand to gauge public opinion on a topic, brand, or event doesn't scale. Businesses and analysts need a fast, automated way to tell whether the conversation around something is trending positive, negative, or neutral.

The solution

I built a text-classification pipeline that takes in raw tweet text and returns a sentiment label with a confidence score. The model is wrapped in a FastAPI backend with a simple Streamlit frontend so it can be used either programmatically (via the API) or through a browser, and the whole thing is containerized with Docker so it runs the same way locally and in production.

Tech stack

Python scikit-learn pandas / numpy TF-IDF Vectorization FastAPI Streamlit Docker Render

Key features & challenges

  • TF-IDF feature engineering to turn raw text into something a classical ML model can learn from effectively.
  • A Logistic Regression classifier, chosen for being fast, interpretable, and strong on this kind of text-classification task.
  • A clean REST API (/health, /predict) with request validation via Pydantic, returning per-class probabilities, not just a single label.
  • Packaging the full stack (model + API + frontend) into a single Docker image for consistent, repeatable deployment to Render.
