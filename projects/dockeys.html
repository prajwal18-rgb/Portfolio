DocKeys — Government Scheme Advisor & Document Tracker

A cross-platform Flutter app that helps people discover government schemes they qualify for, and keeps their documents organized.

GitHub ↗ Final-year diploma project

The problem

A lot of government schemes and bank scholarships go unclaimed simply because the people who qualify for them never find out they exist, or lose track of the documents needed to apply once they do.

The solution

DocKeys is a cross-platform Flutter app with two sides to it. For users: profile-based scheme matching (so you only see schemes you're actually eligible for), a personal document vault to keep required paperwork organized, and notifications when new schemes launch. For admins: a publishing panel to add new schemes and push announcements, backed by Firebase for real-time sync across devices.

Tech stack

Flutter Dart Provider (state management) Go Router Firebase Authentication SharedPreferences file_picker url_launcher

Key features & challenges

  • Designing an eligibility-filtering system flexible enough to match a wide range of scheme criteria against a user's profile.
  • Keeping two very different experiences — a simple user flow and a more admin-heavy publishing flow — cleanly separated inside one codebase and one Firebase backend.
  • Reliable document storage and retrieval across devices using Flutter's file-handling and Firebase together.

Results

Built as my final-year diploma project, with working user and admin flows and real-time Firebase-backed data sync.
