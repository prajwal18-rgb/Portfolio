SafeCityAI — Helmet Violation Detection

A real-time computer vision system that automatically flags riders without helmets in traffic footage, built for smart-city traffic enforcement.

GitHub ↗ Solo project AI/ML Internship Case Study

The problem

Monitoring CCTV footage for helmet violations is one of the most repetitive, time-consuming tasks traffic police deal with — thousands of hours of footage reviewed manually to catch a comparatively small number of violations. That's exactly the kind of pattern-recognition task computer vision is good at automating.

The solution

I fine-tuned a YOLOv5s object-detection model (via transfer learning from COCO weights) to recognize riders with and without helmets, then wrapped it in a FastAPI inference endpoint and built a browser dashboard where you can drag and drop an image or frame and get back bounding boxes, per-detection confidence scores, and a violation count — all in real time.

Tech stack

YOLOv5s PyTorch Google Colab (Tesla T4 GPU) FastAPI Uvicorn Roboflow HTML / CSS / JS Dashboard

Key features & challenges

  • Trained on a 629-image dataset (447 train / 104 val / 78 test) from Roboflow Universe, with mosaic augmentation and horizontal flips to improve detection of small or distant riders.
  • Used Non-Maximum Suppression to clean up duplicate overlapping bounding boxes on the same rider.
  • Balanced precision between the "With Helmet" and "Without Helmet" classes despite a limited training set.
  • Built a dashboard with live scan animation, side-by-side image comparison, and a clear violation vs. all-clear status so the tool is usable by non-technical staff, not just engineers.
