Project · Web Design

Happy Tails — PetPal Store

A stylized, animated storefront site for a pet-shop brand, with a cinematic hero and scroll-driven sections.

GitHub ↗ Live site ↗ Solo project

The problem

Small local shops often end up with generic, template-y websites that don't reflect their brand or make visitors want to stick around. I wanted to see how far a motion-driven, editorial-style frontend could be pushed for a small, everyday business like a pet shop.

The solution

I took a config-driven React template originally built for a luxury travel brand — full-screen hero video, scroll-scrubbed text reveals, a sticky animated panel, membership-style tiers — and reworked it into a pet-shop identity, PetPal Store. The animation engine and layout system stayed the same; the copy, imagery, color story, and content all changed to fit a completely different industry.

Tech stack

React 19 TypeScript Vite Tailwind CSS GSAP + ScrollTrigger Lenis (smooth scroll) Three.js

Key features & challenges

  • Adapting a config system that was designed around one industry's language (travel "journeys" and "tiers") to feel native to a pet shop, without it reading as an obviously reskinned template.
  • Keeping GSAP scroll animations and the Three.js accent panel smooth across different devices and screen sizes.
  • Rebuilding the content, imagery, and tone so the final site reads as a dedicated pet-shop brand rather than a travel site in disguise.

Results

Live and deployed at happy-tails-india.vercel.app.
